🔹 What are Components in React?

🧠 Definition:

A Component in React is a reusable piece of UI (User Interface) that represents part of a web page — like a button, form, navbar, card, etc.

Think of components as building blocks of a React application.

Each component can have its own structure (HTML/JSX), style (CSS), and behavior (JavaScript logic).

📘 Key Points:

Components are independent, reusable, and isolated.

Each component can accept data (called Props).

Components can maintain internal state (using useState or this.state).

Components can be nested inside other components.


🧩 Real-Life Analogy:

A web page (like an eCommerce site) is made of smaller pieces:

Header

Product Card

Footer

Each of these can be made as React components and reused anywhere.

✅ Example of a Component:
function Welcome() {
  return <h1>Hello, Welcome to React!</h1>;
}


You can use it like:

function App() {
  return (
    <div>
      <Welcome />
    </div>
  );
}



🔹 Types of Components in React

There are two main types of components:

Functional Components (Modern, Preferred ✅)

Class Components (Older, Legacy ❌)


🔸 1. Functional Components
🧠 Definition:

A functional component is a simple JavaScript function that returns JSX.
It’s stateless in older React, but with Hooks (like useState, useEffect), it can now handle state and lifecycle logic.

✅ Syntax:
function ComponentName() {
  return (
    <div>
      <h2>This is a Functional Component</h2>
    </div>
  );
}


OR using arrow function:

const ComponentName = () => {
  return <h2>This is a Functional Component</h2>;
};

🧩 Example – Functional Component
function Greeting() {
  const name = "Rahul";
  return <h1>Hello, {name}! Welcome to React.</h1>;
}

function App() {
  return (
    <div>
      <Greeting />
    </div>
  );
}


🖥️ Output:

Hello, Rahul! Welcome to React.

⚙️ Functional Components can use:

Hooks (like useState, useEffect)

Props (for passing data)

JSX syntax

Reusable logic

✅ Modern React uses Functional Components for almost everything.



🔸 2. Class Components (Older Syntax)
🧠 Definition:

A Class Component is a JavaScript class that extends React.Component and implements a render() method that returns JSX.

Before React Hooks (introduced in React 16.8), class components were used for managing state and lifecycle methods.

✅ Syntax:
class ComponentName extends React.Component {
  render() {
    return <h2>This is a Class Component</h2>;
  }
}

🧩 Example – Class Component
import React, { Component } from "react";

class Welcome extends Component {
  render() {
    const name = "Rahul";
    return <h1>Hello, {name}! This is a Class Component.</h1>;
  }
}

export default Welcome;


Use it in App.js:

import Welcome from "./Welcome";

function App() {
  return (
    <div>
      <Welcome />
    </div>
  );
}


🖥️ Output:

Hello, Rahul! This is a Class Component.

⚙️ Class Components Features:

Use this.state for state management.

Use lifecycle methods like componentDidMount(), componentDidUpdate(), componentWillUnmount().

Heavier and more complex than functional components.

📘 Today, class components are rarely used — Hooks make functional components simpler and more powerful.



🔹 Component Creation & Reusability:

🧠 Why Create Reusable Components?

Avoid writing the same code multiple times.

Maintain consistency across the UI.

Easier to update and maintain.

✅ Example – Reusable Card Component
function Card(props) {
  return (
    <div className="card">
      <h2>{props.title}</h2>
      <p>{props.text}</p>
    </div>
  );
}


Now, reuse it multiple times:

function App() {
  return (
    <div>
      <Card title="ReactJS" text="Learn React from scratch" />
      <Card title="JavaScript" text="Master JS fundamentals" />
      <Card title="CSS" text="Style your web pages" />
    </div>
  );
}


🖥️ Output:

ReactJS - Learn React from scratch
JavaScript - Master JS fundamentals
CSS - Style your web pages


✅ Here, one Card component is reused with different props (data).



🔹 Component Naming Conventions

Naming is important in React because:

Components must start with a capital letter (React treats lowercase names as HTML tags).

Use PascalCase for component names.

Type	Convention	Example
Component Name	PascalCase	UserCard, AppHeader, LoginForm
File Name	Same as component	UserCard.js
Props	camelCase	userName, onClick, bgColor
Folder Structure	Components inside /components folder	/src/components/Button.js
✅ Example:
// File: UserProfile.js
function UserProfile(props) {
  return <h3>Hello, {props.name}</h3>;
}

export default UserProfile;

// File: App.js
import UserProfile from "./UserProfile";

function App() {
  return <UserProfile name="Rahul" />;
}


🖥️ Output:

Hello, Rahul



🔹 Component Rendering
🧠 Definition:

Rendering in React means displaying the component’s output (JSX) on the browser.

React renders components into the DOM using the ReactDOM.render() method.

✅ Example:
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(<App />);


App is a React component.

root.render(<App />) tells React to render it inside the HTML element with ID root.

🧩 App.js Example
function App() {
  return (
    <div>
      <h1>My React Application</h1>
      <p>This is rendered inside the root div.</p>
    </div>
  );
}

export default App;

🧩 index.html
<div id="root"></div>

🧩 Browser Output
My React Application
This is rendered inside the root div.
