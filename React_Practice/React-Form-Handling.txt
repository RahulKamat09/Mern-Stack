🚀 Form Handling in React.js —

React handles forms differently than plain HTML because React controls the UI using state.
So understanding state, events, and controlled inputs is important.


✅ 1. What is Form Handling in React? (Definition)

Form Handling in React means:

Managing user input (text, checkbox, radio, dropdown, etc.), storing the values, validating them, and responding when the user submits the form.

Instead of letting the browser handle form values, React uses state to store and update form data.


✅ 2. Controlled vs Uncontrolled Components (VERY IMPORTANT)
2.1 Controlled Components — (Most Common)

A form element whose value is controlled by React State.


Example (Controlled Input):

function MyForm() {
  const [name, setName] = useState("");

  return (
    <div>
      <input
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
      />
      <p>Name: {name}</p>
    </div>
  );
}

✔ Value stored in React state
✔ Best for validation
✔ Most used method


2.2 Uncontrolled Components — (Rarely Used)

Input values are stored inside the HTML element (DOM), not React state.
We use useRef to read the value.

Example (Uncontrolled Input):

function MyForm() {
  const nameRef = useRef();

  const handleSubmit = () => {
    alert(nameRef.current.value);
  };

  return (
    <>
      <input type="text" ref={nameRef} />
      <button onClick={handleSubmit}>Submit</button>
    </>
  );
}


✔ Useful for large forms
✔ Less code but harder validation



🔥 3. Handling Multiple Inputs (Important)

Using one state object for all fields:


function MyForm() {
  const [form, setForm] = useState({
    name: "",
    email: "",
    age: ""
  });

  const handleInput = (e) => {
    setForm({
      ...form,
      [e.target.name]: e.target.value
    });
  };

  return (
    <form>
      <input type="text" name="name" onChange={handleInput} />
      <input type="email" name="email" onChange={handleInput} />
      <input type="number" name="age" onChange={handleInput} />
    </form>
  );
}


✔ Handles many fields
✔ Clean & professional


🎯 4. Handling Form Submit

React prevents page reload using event.preventDefault():

function MyForm() {
  const [name, setName] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault(); // stop reload
    console.log("Form Submitted:", name);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <button type="submit">Submit</button>
    </form>
  );
}

🔐 6. Form Validation (Simple Example):

Example: Required field validation:

function MyForm() {
  const [email, setEmail] = useState("");
  const [error, setError] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault();

    if (!email.includes("@")) {
      setError("Invalid Email!");
      return;
    }

    setError("");
    alert("Submitted Successfully");
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="email" value={email} onChange={(e) => setEmail(e.target.value)} />
      <p style={{ color: "red" }}>{error}</p>
      <button type="submit">Submit</button>
    </form>
  );
}


📦 7. Dynamic Form Fields (Add More Input Fields)

Useful for making "Add More" forms (education, skills, etc.):

function DynamicInputs() {
  const [fields, setFields] = useState([""]);

  const addField = () => setFields([...fields, ""]);

  const handleChange = (i, value) => {
    const updated = [...fields];
    updated[i] = value;
    setFields(updated);
  };

  return (
    <>
      {fields.map((f, i) => (
        <input
          key={i}
          value={f}
          onChange={(e) => handleChange(i, e.target.value)}
        />
      ))}
      <button onClick={addField}>+ Add More</button>
    </>
  );
}

📁 8. File Upload in React:

function FileUpload() {
  const [file, setFile] = useState(null);

  return (
    <div>
      <input
        type="file"
        onChange={(e) => setFile(e.target.files[0])}
      />
      {file && <p>Selected File: {file.name}</p>}
    </div>
  );
}
