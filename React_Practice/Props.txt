✅ What Are Props in React?

Props (short for Properties) are read-only inputs that are passed from a parent component to a child component.
They allow components to be dynamic, reusable, and customizable by sending data and functions between components.

👉 In simple terms:

Props are arguments you pass to React components—just like parameters you pass to a JavaScript function.


🎯 Key Features / Concepts of Props:

✔ 1. Props are read-only

A child cannot modify the props it receives.

✔ 2. Props make components reusable

You can reuse the same component with different values.

✔ 3. Props flow one-way (Top → Down)

Data always travels from parent → child, not the other way.

✔ 4. Props can be any data type

You can pass:

String

Number

Boolean

Array

Object

Function (most important!)

JSX

Components

✔ 5. Props allow communication from parent to child
✔ 6. Props are accessed using:

    props.propertyName

✔ 7. Using destructuring:

    const { name, age } = props;



⭐ Basic Example of Props:

👉 Parent Component:

function App() {
  return (
    <div>
      <Student name="Rahul" age={21} />
    </div>
  );
}

👉 Child Component (receiving props):

function Student(props) {
  return (
    <h2>My name is {props.name} and I am {props.age} years old.</h2>
  );
}

⭐ Using Destructuring (Best Practice):

function Student({ name, age }) {
  return (
    <h2>My name is {name} and I am {age} years old.</h2>
  );
}



🔥 Passing Different Types of Props:


1️⃣ String Props:

<User username="Rahul" />


2️⃣ Number Props:

<User age={20} />


3️⃣ Boolean Props:

<Button disabled={true} />


or shorthand:

<Button disabled />


4️⃣ Array Props:

Parent

const skills = ["HTML", "CSS", "React"];

<Profile skills={skills} />;


Child

function Profile({ skills }) {
  return skills.map((s, i) => <li key={i}>{s}</li>);
}

5️⃣ Object Props:

Parent

const user = { name: "Rahul", age: 22 };

<UserCard info={user} />


Child

function UserCard({ info }) {
  return <h3>{info.name} - {info.age}</h3>;
}


6️⃣ Passing Functions as Props (Very Important):

Used for child → parent communication.

Parent

function Parent() {
  const showMessage = () => {
    alert("Hello from Child!");
  };

  return <Child onClick={showMessage} />;
}

Child

function Child({ onClick }) {
  return <button onClick={onClick}>Click Me</button>;
}


7️⃣ Passing Components as Props (Children Prop):

Every component has a special prop called children.

Parent

<Card>
  <h2>This is inside the Card</h2>
</Card>

Child (Card.js)

function Card({ children }) {
  return <div className="card">{children}</div>;
}


🧩 2. What is Props Drilling? 

Props Drilling happens when you need to pass data from a top-level parent component to a deeply nested child component,
but the data has to pass through multiple intermediate components that don't actually need the data.

👉 In simple words:

Passing props through many layers just so the last component can use it.

Why is it a problem?

Extra code

Hard to maintain

Intermediate components get unnecessary props

Makes component tree messy

Causes unnecessary re-renders


🎯 Example of Props Drilling (3-level component tree):

App → Parent → Child → Button

You want to pass "Rahul" from App to Button, but the middle components don’t need it.


App.js:

function App() {
  const username = "Rahul";

  return <Parent username={username} />;
}


Parent.js:

function Parent({ username }) {
  return <Child username={username} />;
}


Child.js:

function Child({ username }) {
  return <Button username={username} />;
}


Button.js:

function Button({ username }) {
  return <button>Hello {username}</button>;
}


✔ What happened here?

The Parent and Child components do NOT need username,
yet they are forced to pass it forward → This is props drilling.
