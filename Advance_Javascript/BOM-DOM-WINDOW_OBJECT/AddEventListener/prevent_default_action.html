🚫 Prevent Default Action

Stop links or forms from performing their default browser behavior

📘 Concept:
The preventDefault() method stops the browser’s default behavior — like following a link or submitting a form.

🧩 Example:
e.preventDefault(); → stops navigation or default event.

✅ Use Cases:
  • Stop form submission for validation
  • Stop link from navigating
  • Prevent right-click context menu
