🧠 What is addEventListener()?
The addEventListener() method in JavaScript is used to attach an event handler to an HTML element without overwriting existing event handlers. It allows you to listen to specific events — like click, keypress, mouseover, etc. — and execute a function when the event happens.

🧩 Basic Syntax:
element.addEventListener(event, function, useCapture);
element.addEventListener(event, function, options);

⚙️ Parameters Explained:
Parameter Type Description
event String Name of the event (e.g., "click", "mouseover", "keydown")
function Function Callback function to execute when the event occurs
useCapture / options Boolean / Object Determines whether to use capturing or bubbling phase

🔁 Event Flow: When an event occurs (like a click inside nested elements), it passes through:
  1. Capturing Phase: Event travels from the root (HTML) down to the target element.
  2. Target Phase: Event reaches the clicked element.
  3. Bubbling Phase: Event bubbles up from target to root.
