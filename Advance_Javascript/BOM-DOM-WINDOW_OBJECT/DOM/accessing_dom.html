DOM Element Access Methods

This mini project demonstrates all major DOM selection methods with live examples and visible comments.

| Method | Description | Return Type | | ------- | ------------ | ------------ | | getElementById("id") | Returns element with specified ID | Element | | getElementsByClassName("class") | Returns all elements with the given class name | HTMLCollection | | getElementsByTagName("tag") | Returns all elements with the given tag name | HTMLCollection | | querySelector("selector") | Returns first matching element | Element | | querySelectorAll("selector") | Returns all matching elements (NodeList) | NodeList | | getElementsByName("name") | Returns elements by name attribute | NodeList |
