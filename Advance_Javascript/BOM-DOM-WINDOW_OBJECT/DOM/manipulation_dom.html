🧩 DOM Manipulation Methods (Core Modification)

These are the foundation of DOM manipulation — they directly create, modify, or remove elements and their contents.

Method Description Used For
innerHTML Gets or sets HTML code inside an element Add/modify HTML content
textContent Gets or sets plain text Add/modify text safely
createElement() Creates a new HTML element Dynamically create elements
appendChild() Adds a new element as the last child Insert elements into DOM
removeChild() Removes a child element Delete elements

1️⃣ innerHTML

Used to get or set HTML markup inside an element. It can replace existing content with new HTML structure.

⚠️ It parses HTML tags (unlike textContent).

Hello World

2️⃣ textContent

Used to get or set only plain text (HTML tags are treated as text). Safer than innerHTML because it doesn’t interpret HTML tags.

Hello World

3️⃣ createElement()

Used to dynamically create a new HTML element (not yet visible). You can then customize it before adding it to DOM.

4️⃣ appendChild()

Used to insert an element as the last child of a parent. Must be used with a node object (created with createElement()).

  • Apple

5️⃣ removeChild()

Removes a specific child node from its parent element. You must reference both the parent and child nodes.
