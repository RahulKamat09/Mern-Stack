insertAdjacentHTML() Method:

In JavaScript, insertAdjacentHTML() is a method of a DOM element that lets you insert an HTML string into the DOM at a specific position relative to that element, without replacing the existing content. It parses the given string as HTML and inserts the resulting nodes into the DOM. It is faster and safer than innerHTML when you only need to insert HTML, because it does not re-parse the entire element’s content — only the inserted part.

🔹 Syntax:

element.insertAdjacentHTML(position, text);

element → The DOM node you want to insert content into.
position → A string that defines where to insert the HTML (relative to the element).
text → The HTML string to be inserted.

🔹 Positions Available:

The position parameter accepts 4 values:
'beforebegin' → Insert before the element itself.
'afterbegin' → Insert inside the element, before its first child.
'beforeend' → Insert inside the element, after its last child.
'afterend' → Insert after the element itself.
