🎯 Using Options Object in addEventListener()

Execute Event Only Once Using `{ once: true }`

3️⃣ Using Options Object:
Instead of passing just true or false as the third parameter, you can pass an options object.

For example: { once: true } — means the event will be executed only once, and then automatically removed.
