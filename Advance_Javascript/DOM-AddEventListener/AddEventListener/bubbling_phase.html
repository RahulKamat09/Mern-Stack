🧩 Event Bubbling in JavaScript

Understanding how events propagate through parent and child elements

Parent
Click on buttons to see event order!
🧠 Concept:
When you click on a child element, the event first triggers the child’s event handler, and then “bubbles up” to the parent element.

🧩 Output (Click on Child):
1️⃣ Child clicked!
2️⃣ Parent clicked!

This is called Event Bubbling.
