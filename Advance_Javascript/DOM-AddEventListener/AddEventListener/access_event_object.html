🧠 Accessing Event Object

Learn how event objects hold details about user interactions

Click the button to display event details here!
📘 Concept:
Every event listener automatically receives an event object (commonly named e or event) that contains useful information about the event triggered.

🧩 Example:
element.addEventListener("click", function(e) { console.log(e.type); });

✅ Common Properties:
  • event.type → Type of event (e.g., click, keydown)
  • event.target → Element that triggered the event
  • event.clientX, event.clientY → Mouse cursor position
  • event.preventDefault() → Stops default browser action
  • event.stopPropagation() → Stops event bubbling/capturing
