🔹 Attribute and Style Manipulation

These methods modify existing elements’ attributes and visual styles, without changing the DOM structure.

Method Description Used For
setAttribute() Add or modify an attribute Change element behavior
getAttribute() Get the value of an attribute Read existing attributes
removeAttribute() Delete an attribute Remove properties
style.property Change CSS property directly Inline CSS
classList.add() / remove() / toggle() Add, remove, or toggle CSS classes Manage styles dynamically

6️⃣ setAttribute()

Adds or changes an HTML attribute dynamically (e.g., src, href, id).

7️⃣ getAttribute()

Returns the current value of an attribute from an element.

8️⃣ removeAttribute()

Deletes a specific attribute (like src, alt, etc.) from an element.

9️⃣ style.property

Directly modifies CSS properties of an element (inline). Use camelCase for multi-word properties.
