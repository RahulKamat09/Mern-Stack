📘 Concept:
Upward traversal means moving from a child element to its parent or ancestor elements in the DOM tree.

🔹 Common Methods:
  • element.parentElement → Returns the direct parent element
  • element.closest(selector) → Returns the nearest ancestor (including itself) that matches a selector
