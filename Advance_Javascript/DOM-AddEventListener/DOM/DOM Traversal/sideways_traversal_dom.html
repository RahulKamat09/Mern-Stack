📘 Concept:
Sideways traversal helps move between elements that share the same parent — also known as siblings.

🔹 Common Methods:
  • element.nextElementSibling → Moves to the next sibling (right side)
  • element.previousElementSibling → Moves to the previous sibling (left side)
