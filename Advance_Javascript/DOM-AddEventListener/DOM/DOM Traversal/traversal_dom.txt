🌳 What is DOM Traversal?

Traversal in the Document Object Model (DOM) means navigating or moving through elements of an HTML document.

When a web page is loaded, the browser creates a DOM tree structure where:

Each HTML tag is a node

You can move (traverse) between parent, child, or sibling nodes

By using DOM Traversal Methods, we can easily access, move, or modify elements dynamically.


🧩 DOM Tree Structure Example:
Let’s start with a small HTML to visualize the structure 👇

<!DOCTYPE html>
<html>
  <body>
    <div id="container">
      <h1>Title</h1>
      <p>Paragraph 1</p>
      <p>Paragraph 2</p>
    </div>
  </body>
</html>


DOM Tree:

document
 └── html
      └── body
           └── div#container
                ├── h1
                ├── p (Paragraph 1)
                └── p (Paragraph 2)


Now, let’s understand how we can traverse this structure.


🧠 DOM Traversal Types:
There are mainly 3 traversal directions:

| Direction              | Meaning                       |
| ---------------------- | ----------------------------- |
| **Upward Traversal**   | Move from child → parent      |
| **Downward Traversal** | Move from parent → child      |
| **Sideways Traversal** | Move between sibling elements |


🔹 1. Downward Traversal (Parent → Child)

Used to go inside an element (find its children).

➤ element.children :

Returns all child elements (HTML tags) (not text or comment nodes).

Returns an HTMLCollection (array-like object).

Example:

<div id="box">
  <p>Para 1</p>
  <p>Para 2</p>
</div>

<script>
  let box = document.getElementById("box");
  console.log(box.children);        // HTMLCollection(2) [p, p]
  console.log(box.children[0]);     // <p>Para 1</p>
</script>


➤ element.firstElementChild :

Returns the first child element.

console.log(box.firstElementChild);  // <p>Para 1</p>


➤ element.lastElementChild :

Returns the last child element.

console.log(box.lastElementChild);   // <p>Para 2</p>


➤ element.querySelector() and element.querySelectorAll() :

These can also be used for downward traversal (search inside an element).

console.log(box.querySelector("p"));        // First <p>
console.log(box.querySelectorAll("p"));     // All <p> elements



🔹 2. Upward Traversal (Child → Parent)

Used to go upward from a child to its parent element.


➤ element.parentElement:

Returns the direct parent element.

<p id="para">Hello World</p>

<script>
  let para = document.getElementById("para");
  console.log(para.parentElement);  // <body>...</body>
</script>


➤ element.closest(selector):

Finds the nearest ancestor (including itself) that matches a specific selector.

Example:

<div class="outer">
  <div class="inner">
    <p id="text">This is a paragraph.</p>
  </div>
</div>

<script>
  let para = document.getElementById("text");
  console.log(para.closest(".outer")); // <div class="outer">...</div>
</script>


🔹 3. Sideways Traversal (Siblings)

Used to move between elements sharing the same parent.


➤ element.nextElementSibling :

Moves to the next sibling (right side).

<ul>
  <li>Home</li>
  <li id="about">About</li>
  <li>Contact</li>
</ul>

<script>
  let about = document.getElementById("about");
  console.log(about.nextElementSibling);  // <li>Contact</li>
</script>


➤ element.previousElementSibling :

Moves to the previous sibling (left side).

console.log(about.previousElementSibling); // <li>Home</li>


🔹 4. Accessing All Nodes (including text/comments)

If you want to include text nodes, comments, and whitespace, you can use:

| Property                   | Description                                       |
| -------------------------- | ------------------------------------------------- |
| `childNodes`               | Includes **all nodes** (elements, text, comments) |
| `firstChild` / `lastChild` | Include **any type of node** (not just elements)  |

<div id="box">
  Text
  <p>Hello</p>
</div>

<script>
  let box = document.getElementById("box");
  console.log(box.childNodes); // NodeList(3): [text, p, text]
</script>


🔹 5. Traversing the Entire DOM

You can combine these methods to move anywhere in the DOM tree.

Example:

<div id="container">
  <h1>Heading</h1>
  <p>Paragraph</p>
</div>

<script>
  let div = document.getElementById("container");
  let firstChild = div.firstElementChild;     // <h1>
  let nextSibling = firstChild.nextElementSibling; // <p>
  let parent = nextSibling.parentElement;     // <div id="container">
  
  console.log(firstChild.textContent);  // "Heading"
  console.log(nextSibling.textContent); // "Paragraph"
  console.log(parent.id);               // "container"
</script>


💡 Tip: Difference Between children vs childNodes:

| Property       | Includes                                  | Type Returned  |
| -------------- | ----------------------------------------- | -------------- |
| **children**   | Only element nodes (tags)                 | HTMLCollection |
| **childNodes** | All node types (text, comments, elements) | NodeList       |


🧮 Quick Summary Table:

| Traversal Type | Method                   | Description                        |
| -------------- | ------------------------ | ---------------------------------- |
| Downward       | `children`               | All child elements                 |
| Downward       | `firstElementChild`      | First child element                |
| Downward       | `lastElementChild`       | Last child element                 |
| Upward         | `parentElement`          | Direct parent                      |
| Upward         | `closest(selector)`      | Closest ancestor matching selector |
| Sideways       | `nextElementSibling`     | Next sibling element               |
| Sideways       | `previousElementSibling` | Previous sibling element           |
| Nodes          | `childNodes`             | All nodes (text, element, etc.)    |



🧾 Final Notes

✅ Traversal is essential for interacting dynamically with the DOM
✅ Helps you navigate, read, or modify elements
✅ Common in frameworks like React, Vue, Angular under the hood
✅ Understanding this makes manipulation and event handling easier
