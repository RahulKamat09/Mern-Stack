📘 Concept:
Downward traversal means moving from a parent element to its child elements in the DOM tree.

🔹 Common Methods:
  • element.children → All child elements
  • element.firstElementChild → First child element
  • element.lastElementChild → Last child element
  • element.querySelector() / querySelectorAll() → Find elements inside another element
