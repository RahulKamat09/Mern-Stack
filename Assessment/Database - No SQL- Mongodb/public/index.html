1. Node.js & Real-Time APIs

Node.js is preferred because it runs on a single-threaded event loop using **non-blocking I/O**. Traditional architectures allocate one heavy thread per client, exhausting memory quickly under high concurrency (e.g. holding thousands of open WebSocket paths). Node.js holds connections open with minimal memory overhead, responding as events resolve.

3. Promises vs Callback Hell

Callbacks force deep nesting (the Pyramid of Doom), repeating complex exception checks at every level. **Promises flatten execution** into structured chains (.then().catch()) representing eventual state fulfillment. Modern async/await lets asynchronous interactions follow a standard linear design, looking like clean synchronous routines with try/catch logic.

4. Document Catalogs in MongoDB

SQL splits product details into strict relational tables (categories, attributes, stocks) that require performance-heavy JOIN joins. MongoDB embeds multi-tiered datasets (sub-documents, specifications, variations) inside a **single BSON document**. Reading a product retrieves its complete nested catalog block in one fast operation.
